# MIRAGE 4.3 — Main release candidate

## Интерфейс

- STEALTH — светлая тема; SPECTRE — тёмная экспертная тема.
- Выбранный режим хранится в профиле и локально для быстрого первого отображения.
- Основные вкладки: Главная, Торговля, Аналитика, Новости, Профиль.
- Сохранены существующие Market, Signals, Strategy Lab, Research, Robustness и News модули.
- Исправлена тема meta-color для светлого STEALTH режима.
- Сохранены штатные CSS и настоящая аватарка из `frontend/mirage-avatar-512.png`; старые конкурирующие навигационные скрипты не подключаются из основного HTML.

## Пользователи и Paper Trading

- Telegram-ID профили, приглашения владельцем, ограничение числа активных пользователей.
- Независимые Paper Trading счета, позиции, сделки, история и статистика каждого пользователя.
- Каждый новый пользователь получает четыре Paper-счёта по $2,500 (всего $10,000).
- Общие рыночные сигналы не смешивают пользовательские портфели.
- Ручное закрытие Paper-позиции записывает `MANUAL_CLOSE`: P&L учитывается, Win Rate — нет.
- Доставка сигналов ведётся отдельно по каждому Telegram-получателю с защитой от дублирования.

## Exchange Center

- Binance и Bybit: read-only проверка API-ключей и зашифрованное хранение на сервере.
- Добавлен read-only запрос баланса/активов через подключённый ключ.
- Binance отображает native asset balances без искусственной USD-оценки; Bybit может возвращать предоставленную биржей USD equity.
- Binance withdrawal permission проверяется по ответу API; Bybit требует ручного подтверждения в настройках ключа.
- Disconnect удаляет локальные зашифрованные ключи; API key на самой бирже пользователь отзывает отдельно.

## PROTOCOL PHANTOM

- Добавлено постоянное поле `users.phantom_locked` с безопасной миграцией для существующей БД.
- Активация переключает пользователя в Paper, блокирует и помечает сохранённые подключения как locked.
- Повторное подключение запрещено, пока пользователь явно не введёт `UNLOCK MIRAGE`.
- После разблокировки ранее заблокированные подключения не активируются автоматически: требуется повторная проверка ключей.

## Ограничение Live

- Live order execution, order cancel, reduce-only close, live position sync и remote key revoke не реализованы.
- `trading_mode=live` отклоняется backend; Live остаётся принудительно выключен.
- PROTOCOL PHANTOM в этом релизе блокирует действия MIRAGE и не заявляет, что закрывает биржевые позиции или отзывает ключи.
